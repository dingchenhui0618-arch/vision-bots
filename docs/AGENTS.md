# Bot 是一个 agent 会话，不是一个 handler

四个 bot（制片人 / 剪辑 / 包装 / 质检）用的是同一套工具代码；模型各走各的配置（config/bots/<id>.json），可以连不同档、不同厂的模型。
不同的只有三件事：职责、红线、各自的会话目录。

```
groups/<id>/bots/<botId>/
  history.jsonl   说过的话、收到的任务（一行一条，append）
  notes.json      它自己决定要记住的结论（上限 24 条，同 key 覆盖）
```

会话是长驻的：这个项目里它听过什么、做过什么决定，下一轮接着用。CLI 重开也能从盘上重建
（`src/agent/session.mjs`）。

## 一轮是怎么跑的

```
用户一句话
  ↓
Orchestrator（状态机 + 硬门）
  ↓
Director.producerTurn()          ← 制片人的会话
  ↓  模型自己决定
  ├─ inspect_project             「素材多长、要多久、能不能达标」
  ├─ dispatch_to(cutter, 任务)    → 剪辑的会话跑一轮 → 结论回流
  ├─ dispatch_to(packer, 任务)    → 包装的会话跑一轮 → 结论回流
  ├─ dispatch_to(qc, 任务)        → 质检的会话跑一轮 → 结论回流
  └─ finish_delivery             「质检跑过了才调得通」
  ↓
群里出现的是每个 bot 自己说的话（模型写的，数字来自工具）
```

`src/agent/loop.mjs` 就是那个循环：模型选工具 → 执行 → 结果回给模型 → 直到它说出一句话。
`src/agent/director.mjs` 是协调层：谁在什么时候被谁叫起来、它的结论怎么回到上一级。

## 三条硬规矩是代码，不是提示词

1. **干活只能通过工具。** 模型的输出只有两种：调工具，或者说话。它没有别的手。
2. **说的每个数字必须有出处。** `src/agent/facts.mjs` 把这一轮所有工具返回里的数字收进事实表，
   bot 说的话里每个数字都要能在里面找到。找不到就重写一次；还编，就把那几个数标在话后面
   交出去（`unverified-numbers`），不静默放过。
3. **层级是代码定的。** 只有制片人的工具表里有 `dispatch_to`；剪辑、包装、质检没有。
   所以「小 bot 会不会自己再往下派」不是靠提示词约束的。`Director.depth > 2` 直接停。

## 四个 bot 各自的红线（写进 system，也写进验收）

| bot | 红线 |
|---|---|
| 制片人 | 不自己剪/渲；达不到目标就报差额；质检没跑过不许交付；派活要说验收标准 |
| 剪辑 | 只改词的文本，词数和每个词的起止时间码不许动；没把握的词不改但要说 |
| 包装 | 模板没做的画幅不许静默改尺寸；改一句只重渲受影响帧；慢了直接说多少倍 |
| 质检 | 没有证据不许判通过；只能加严；失败项给帧号或数值 |

## 交付硬门

`Director.deliver()` 不看模型怎么想，只查两件事：

- `state.report` 不存在（质检没跑）→ 拒绝交付，返回原因给模型。
- 已经交付过 → 拒绝重复交付。

质检跑过但没过，允许交付——但失败项逐条带出来，Orchestrator 另外在系统层补一条
「N 项没过」的提示。目标时长与成片对不上（>6%，自测16 起从 12% 收紧）
也在系统层补一条差额，模型说不说是它的事，事实藏不住。

剪辑现在有「整句删」（src/prune.mjs）：目标时长进决策，模型提案删哪句、规则逐条核
（钩子/落点/唯一信息/悬空/半句），再按「离目标最近」枚举子集，最后重跑 buildPlan——
刀口和接缝照旧，时间码一个字节不动。

## 模板句去哪了

以前的模板句（「读完了：X 秒素材，剪掉 Y 秒」）现在全部走 `group.note()`，是**系统提示**，
不挂 bot 头像。群聊里带 bot 头像的每一句话都来自模型。

## 离线自测

`node scripts/check-agent.mjs`（35 条，不联网、不碰真素材）：

- 事实表：精确命中 / 整数近似 / 编造被拦 / 违规数字逐个列出
- 会话：落盘能重建、同 key 覆盖、不同 bot 互不干扰
- 循环：先调工具再说话；编了数被打回重写；死不认账被标记
- 名册：各自红线、层级不越权、工具不重样；模型不写死在名册里（在 config/bots/<id>.json）
- 配置：改一个 bot 的模型/温度/参数不影响另外三个（check-bots 27 条）
- 硬门：没质检不许交、不许重复交
