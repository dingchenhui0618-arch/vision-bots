# 折光模板（zheguang）

对齐目标：用户给的案例片 `C:\Users\123\Desktop\素材及测试视频图\案例视频折光\成片.mp4`（720×1280、30fps、70.47s、2114 帧）。
本模板用同一份原素材（原素材.mp4，72.17s、VFR、720×1280）出片，目标不是逐帧复刻，而是把它的**设计系统**搬进产品：
版式轮换的节奏、章节卡与页码 HUD、语义强调大字、图形块、字幕关键词高亮。

## 1. 参考片拆解（逐秒测绘的结论）

| 维度 | 参考片 |
| --- | --- |
| 常驻 HUD | 左上 `P. 01 / 08`；右上白胶囊「● 主题 + 时间码 00:04:13」；底部细进度线 |
| 章节卡 | 绿色两位数字 + 白色章节名 + 「现状 · STATUS」小字眉，页边界必落，停约 1.8s |
| 大字 | 语义强调卡：一行一条、可逐行上屏；关键词用黄字 / 荧光绿底黑字 / 红底反白 |
| 字幕 | 底部深色圆角块，白字，关键词在行内换色（不换字） |
| 版式 | 满幅 / 竖框居中 / 右上小窗 / 全屏色卡（荧光绿底黑字）/ 章节卡 / 结尾画中画，共 6 种 |
| 图形块 | 标签墙、刻度卡（不带数字）、药丸列表、对勾卡、红条打叉、数据线、名片卡（作者）、手机框 |
| 节奏 | 70.5s 分 8 个 page；大约每 6–9 秒换一次构图；全片 1 次全屏色卡、1 段竖框、2–3 次小窗 |

## 2. 我们落地的东西

### 2.1 设计变量（`templates/zheguang/template.json`）

- 色：`void #0B0B0C`、`paper #F4F2EC`、`lime #D8FF3E`、`green #35E07A`、`yellow #F5E13C`、`red #E23A2C`、`ash #8C8B85`
- 字阶（9:16 / 1080×1920）：brand 21 · page 22 · eyebrow 21 · chapterNum 84 · chapterTitle 54 · big 96（最小 62）· sub 42（两行时 34）· block 26
- 几何：边距 56；HUD y=92；章节卡 y=300；大字左边 62、右边让 150（平台按钮区）；字幕底距 236；进度线 y=1852
- 画幅：9:16（默认）与 3:4 各一套，换画幅不动时间线

### 2.2 六种版式

| kind | 什么时候用 | 谁决定 |
| --- | --- | --- |
| `full` | 默认，人在说话 | — |
| `corner` | 转折句（但是/所以/其实）或满幅超过 11 秒要呼吸 | 分镜提案，或引擎补节奏 |
| `frame` | 一段里连着列好几样东西（短句连发） | 分镜提案（要过「真有列举」校验） |
| `card` | 一句 6 字以内的金句/反问，占满屏 | 分镜提案必须引用该页真实的一句卡；引擎可补 1 次 |
| `chapter` | 页边界叠章节卡（1.8s，不改变版式） | 数据层 |
| `outro` | 最后 2.6 秒人物收进竖屏框 + END + 页标题 | 数据层 |

配额：card ≤ 2、frame ≤ 1、corner ≤ 4。超了就退回满幅并记账——不是悄悄降级。

### 2.3 图形块

`tagwall`（标签墙，只配竖框/小窗，满幅会压脸）、`check`（对勾卡）、`banner`（红条打叉，只在满幅）、`gauge`（刻度卡，不带数值）、`avatar`（名片卡，只有 brief 里给了作者才画）。

所有块里的字都必须是本页原话里出现过的：校验器逐条查，查不过就整块丢掉并写进 problems。

### 2.4 分镜是剪辑的事，不是包装的事

1. 剪辑在出完字幕卡后，把「段落 → 8 页」的骨架交给 `src/shots.mjs`；
2. 模型（qwen3.8-flash）为每页提案：章节名、小字眉、版式、强调词、图形块；
3. `validateProposal` 逐条校验（接地 / 长度 / 是否真有列举 / 配额 / 数字守卫），不合格的退回兜底值并记账；
4. 提案存进 `pipeline.json` 的 `shots` 字段；包装只负责把意图落成时间窗口和像素，改一句重跑不会重排分镜；
5. 模型不可用 → 全链路确定性兜底（页标题按词窗口摘句、版式按规则挑、引擎补节奏），片子照出。

## 3. 硬不变量（`scripts/check-zheguang.mjs`）

- 页：3–8 页、起点递增、不重叠、第一页从 0 开始、最后一页盖到片尾 1s 内
- 版式：按时间有序、不重叠、从 0 铺到片尾、种类合法、配额不超、结尾必是 outro
- 大字：每条都取自本页原话（多重集合接地）、≤ 8 字、互不重叠、每条都有版式归
- 图形块：只能在支持的版式里、文字来自原话
- 章节名：不以虚词收尾、≤ 8 字
- 加 `--render`：跑一遍版式采样，验「大字不压字幕」（盒子级）

## 4. 已知差距（不粉饰）

1. **人物蒙版没做**：参考片的标签墙压在人物身后（被帽子遮挡），我们现在只能放在竖框/小窗的黑区里。Windows 侧 ONNX 人像抠像仍是未开工项。
2. **标签墙很少出现**：它要求原话里真有一组同类名词，这段素材只有「GPT / Claude / Codex」一处，被分镜打了回。
3. **ASR 残留错字会污染章节名与大字**：`指纹住在`→`只有专注在`、`网到`→`王道`、`GDP`→`GPT` 仍未修，分镜只能摘原话，摘到错的就跟着错。这需要跨词等长替换，不是模板层能解决的。
4. **3:4 只做了几何**，没有用真素材验过观感。
5. **动效克制**：参考片有上滑/缩放入场、数字滚动、圆环脉冲；我们只做了硬切 + 0.26–0.4s 的淡入/位移，没有做逐帧编排的转场。
6. **字体近似**：参考片用的是更紧凑的重黑，我们用 Noto Sans SC 900（Archivo 压缩体做 HUD），字面比参考片略宽。
